# BudgetWise

BudgetWise is a Flutter personal-finance app prototype for tracking balances,
transactions, budgets, and spending reports.

## Features

- Onboarding and sign-in screens
- Dashboard with balance, income, expenses, and recent transactions
- Transactions, budget tracking, and spending reports
- Profile and preferences screens

## Run locally

Install the Flutter SDK, then from this directory run:

```shell
flutter pub get
flutter run
```

Run the widget tests with:

```shell
flutter test
```
